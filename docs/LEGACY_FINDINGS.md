# SecureVault C01–C06 audit register

This audit covers a standalone desktop CLI with concurrent local invocations, the C06 key hierarchy library, and the coursework evidence pipeline. The baseline was `7d2df398967acd74409cc3b43209d8a36649c9a4`. Sources were the original CW1 descriptor, architecture §§9–11, repository requirements and conformance docs, and the code and history at the baseline. The managed vault and assessment report have separate acceptance gates.
